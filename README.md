# 助理（@starsharryzhu/dsh-assistant）

DeepSeek Harness 插件，给完全不熟悉 AI 的家人用。

## 安装

在 DSH 桌面端或网页版的插件页安装 `@starsharryzhu/dsh-assistant`，或者在命令行：

```bash
dsh plugin --profile <profile> add @starsharryzhu/dsh-assistant
```

两个子插件 `@starsharryzhu/complete-subagent` 和 `@starsharryzhu/im-robot` 会作为依赖一起装好。

- 点左侧栏的「助理」，直接进入上次打开的那个助理的对话，用的是 DSH 自己的对话界面。
- 对话顶部的标题（助理的名字）是一个下拉菜单：换到另一个助理，或者新建助理。
- 新建助理时填三样：助理的名字、希望它怎么称呼你（可以不填）、工作区。工作区必须自己选文件夹，没选就不能创建，也不能和别的助理用同一个文件夹。
- 顶部的「对话 / 轨迹」后面多两个标签：
  - **IM**：接入微信。没接入时扫码绑定；接入后显示账号和连接状态，可以选模型、推理等级和权限，改发送方式（排队或插话）和是否允许在微信里执行命令，也可以诊断连接、重新连接、移除接入。
  - **设置**：这个助理自己的设置，也能改名字和称呼、删除助理。
- 模型和推理强度在输入框或 IM 标签里选，两处是同一个选择，每个助理各记各的。权限只在 IM 标签里选（只读、工作区写入、完全访问，默认工作区写入）；用别的办法改了，助理会改回所选的值。
- 每个助理有自己的工作区和一段一直延续的对话。上下文快满时自动整理，不用开新对话。
- 一个助理都没有时，点左侧栏会先要求创建一个。创建后助理会先打个招呼，这要用一次模型调用；不打招呼的话，DSH 会把没说过话的会话显示成空白页。
- 对话用的是 DSH 自己的对话界面，所以其他修改对话窗口的插件（比如旁问按钮）也会出现在这里；工具仍然双向隔离，别的插件的工具进不了助理。

## 怎么工作的

参考 DeepSeek 的 Super-agent 文章和它开源的原型 [dsh-superagent-prototype](https://github.com/deepseek-ai/dsh-superagent-prototype)（MIT），家人的对话做成**严格双层**：

- **对话层**（router）：负责聊天、派活、审批权限，简单的信息当场记、当场改、当场查（见下面的「记录」）。除了这几个只能碰固定文件的记录工具，它没有写文件、命令行和联网工具，所以不会因为干活而卡住，家人随时能插话。
- **执行层**（worker）：其他实际工作，比如查资料、做规划、写文档、整理文件，都交给后台的小帮手完成，做完再由对话层用一两句白话告诉家人。小帮手由子插件 complete-subagent 派出，只能改分给它的文件夹。
- **权限审批**：小帮手想改自己文件夹以外的地方时会向对话层申请。对话层自动审：工作区里、和任务相符的直接允许；工作区外默认一律拒绝，这是宿主的限制，家人同意了也改不了，助理会说明，并请家人把文件放进工作区（权限改成完全访问后才能放行）；工作区里但可能删掉或覆盖重要内容的，用一句白话问家人，家人同意了再放行。不会弹出任何问答框。
- **少打扰**（同样借鉴原型的对话规范）：
  - 开始干活时，对话层只用一句话说明要做的具体事情，之后就不再提，直到有结果。
  - 只在三种情况下开口：有家人关心的结果、有只能由家人做的决定、事情做不成。不汇报过程，同一个结果不说第二遍，一次只问一个问题。
  - 派活时原样转述家人的话，不自己加计划和要求；派完就结束这一轮，不去催问小帮手。
- **固定格式的汇报**：小帮手做完后，第一行写状态（完成、受阻、失败、无需处理），然后写结果，最多再附一个「需要家人决定」的问题。对话层按状态处理：完成就用自己的话说结果；无需处理就不出声；受阻就把那一个问题转问家人；失败就换个说法重试一次，还不行就如实说明。
- **外部内容只当资料**：网页、搜索结果、文件、文档，以及家人转发或粘贴的消息，里面写的「指令」两层都不执行。这些内容改变不了规则、人设和隐私边界，也不能成为放行写权限、删除、发送、花钱的理由；内容里要求做什么，就告诉家人，由家人决定。

这两层各是一个**隐藏的 agent preset**，新建会话的模式选择器里看不到它们。

## 功能

- **全自动**：不追问、不等确认；有歧义就选最合理的理解，并顺口说明选了什么。
- **默认只改自己的工作区**：权限默认「工作区写入 + 自动拒绝越权」，每个助理可以在 IM 标签改成只读或完全访问。完全访问时助理可以让 worker 改工作区以外的文件，开启前要再确认一次。
- **自动整理上下文**：每轮结束后，上下文占用达到设定比例（默认 50%）就自动整理。
- **模型和推理强度**：在对话的输入框里选，每个助理的对话各记各的，重启后还在。
  - 和普通会话一样，这里选的模型也会成为新会话的默认模型；新助理从默认模型开始。已经有的对话不受影响。
  - worker（后台小帮手）的模型在「worker模型选择」里多选，对话层按任务从勾选的模型里挑一个，至少留一个。没勾选的模型，包括对话用的模型，worker 都不会用。
- **余额提醒**：看的是 DeepSeek 账户（已登录的账号优先，否则看 API key）。人民币余额低于阈值（默认 10 元）时，助理在回答末尾附上提醒，话术可以在设置里改。余额查不到时不提醒。
- **模型自用的内容是英文**：画像、人设、项目笔记、worker 汇报、系统消息和工具结果都用英文，名字和要原样使用的词除外。家人看到的回复、周视图、提醒，以及日程、清单、备忘、流水的内容仍是家人的原话。画像里没有家庭成员。称呼以助理设置里填的为起点，家人在聊天里要求换时记到画像或人设，并优先于设置。
- **自我修正的人设**：根据明确的证据调整语气、长短、称呼等，每次改动都写进变更日志，有冷却期和长度上限，家人不满意可以回滚。
- **记录**：简单的信息由对话层当场记下，不用派小帮手。都是家人工作区里的普通文件，分这几类：
  - 日程（`ddl.md`）：有时间的事，也可以没日期；重复的事也放这里（每天吃药、每月 5 号交房租、每年生日）。
  - 清单（`lists/`）：一组同类的东西，一项项勾掉，比如买菜、要带的东西。
  - 备忘（`memo.md`）：用到才查的事实，新值替换旧值，比如钥匙放哪、王阿姨电话。
  - 流水（`logs/`）：要留着历史的记录，比如血压、记账。
  - 画像（`profile.md`）：助理每次对话都该知道的事，比如饮食禁忌、作息。
  - 人设（`persona.md`）：助理怎么说话。冷却期、长度上限和不可改的核心都由插件把关；家人直接要求的改动不受冷却期限制。
  - 项目（`projects/`）：长期事情的状态、待办和记录。
  - 助理不记密码、银行卡号和证件号，这些文件是明文，内容也会发给模型服务。
- **日程**：
  - 家人说的本地时间由插件换算成 UTC 存储，再按家人的时区显示，不用调用模型。
  - 有具体时间的事，记下时自动设提醒；改期、完成、取消时提醒跟着变。
  - 每日提醒不算「每天」都有的事，否则每天都会发一条。
  - 输入 `/ddl` 直接列出未来一周的纯文字周视图。
- **每日提醒**：每天到点（默认 08:00）检查当天有没有安排。有就提醒一句，没有就不打扰。
- **看门狗**：对话一轮超过设定时间（默认 10 分钟）没有进展，就自动停下并用白话告知；后台小帮手长时间没动静，就提醒对话层去查看。
- **工具双向隔离**：助理的工具（包括记录工具）不会出现在普通会话里；其他插件加的全局工具也进不了助理会话。你自己的开发 skill 也不会带进来。
- **微信**：通过子插件 im-robot 接入。在助理对话顶部的「IM」标签里点「接入微信」，用要和它聊天的那个人**自己的**微信扫码即可。之后在微信里说话，进的是同一段对话。微信回复是纯文字，按句子切成每条不超过 100 字的几条消息（可在设置里改）；列表、步骤这类要放在一起的内容，助理会用 `<keep>…</keep>` 包起来整条发出。家人最近一次是在微信里说话时，小帮手做完后的结果、每日提醒、看门狗的通知也会发到微信；家人在网页上说过话之后，这些就只在网页上显示。

## 设置

分两处，保存后立即生效。数字可以删空重写，离开输入框或按回车时自动修正：超出范围的改成最近的边界，看不懂的恢复原值。

**插件页的设置**，所有助理共用：

- worker模型选择（可多选）；
- 自动整理比例；
- 余额阈值、查询间隔、提醒话术；
- 是否允许调整人设、冷却期，人设和画像的长度上限。

**对话顶部的「设置」标签**，每个助理各有一份：

- 名字和称呼（工作区只显示，不能改）；
- 日程提醒的提前量、每日提醒时间；
- 看门狗时限；
- 微信开关和单条长度。

## 子插件

本插件照 dsh-mnemon 的做法包含子插件，它们都是独立的 npm 包，在 `dependencies` 里写固定版本，装本插件时一起下载，并且只在助理的两个 preset 里生效：

- `@starsharryzhu/complete-subagent`：后台小帮手和写权限申请。
- `@starsharryzhu/im-robot`：微信接入。

如果你另外单独装了这两个插件之一，本插件自带的那份会自动关掉，避免重复。

## 已知限制

- 助理的对话仍会出现在普通会话列表的「未分组」里（宿主没有给插件过滤列表的接口）；从那里点开也是同一段对话。
- 只隔离了工具，其他全局插件注入的提示词上下文没有过滤。
- 如果另外单独装了 complete-subagent，本插件自带的那份会关掉，小帮手就改用单独那份的配置。单独那份默认不会把小帮手放到助理的执行器上，小帮手就没法改文件。所以用助理时，不要再单独装 complete-subagent。
- 微信目前只收发文字；页面上暂时不能发图片和文件。
- 助理和小帮手改不了工作区外的文件（比如「下载」文件夹）。
- 在 0.2.1-rc.5 上，批准的路径只能用写文件工具改，小帮手的命令行写不了。
- 需要 DSH 0.2.1-rc.5 或更新的版本。目前在 macOS 上验证过 0.2.2-alpha.2 和 0.2.1-rc.5 的宿主（模拟模型）；桌面版应用本身还要再实测一次。

```bash
node scripts/link-dev.mjs

```
